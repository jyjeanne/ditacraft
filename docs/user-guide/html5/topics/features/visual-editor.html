Visual Editor

Edit a DITA topic on a page that looks like your output, while DITA Craft writes clean XML: every change reaches the file as a small, precise text edit, and everything you do not touch stays exactly as it was.

Overview

The visual editor shows a topic as a page — headings, paragraphs, notes, steps, lists, tables, figures — and lets you edit it right there. It is built from the same grammars as the visual preview, so the page follows your document type: the styles, menus and the Enter key only offer what the DTD allows at the cursor, and specialized elements behave like the element they specialize.

The visual editor is an alternative editor for .dita, .ditamap and .bookmap files: the text editor stays the default, and both edit the same document. Open a topic or a map with DITA: Open in Visual Editor.

What You Can Do

  • Write on the page: paragraphs, lists, steps, styles and any element your DTD allows, from the keyboard, the toolbar or the right-click menu.
  • Edit CALS and simple tables, and drag column borders to set widths.
  • Insert, paste, drop and resize images; link to elements, keys, topics and web addresses from a picker.
  • See reused content, keys' texts and link titles resolved; open the source of reused content or make a local copy.
  • See the language server's problems on the page and apply their quick fixes.
  • Work on maps and bookmaps: one row per reference with the title of its topic, folded and opened from the page.
  • Edit attributes in the Properties view, and work side by side with the XML.
  • Working in the Visual Editor
    Open a topic in the visual editor, find your way around the page, work side by side with the XML, and know what reaches the file.
  • Writing on the Page
    Type, make lists and steps, apply styles, and insert any element your document type allows — from the keyboard, the toolbar or the right-click menu.
  • Tables in the Visual Editor
    Insert and edit CALS and simple tables on the page: rows, columns, merged cells and column widths, with the table markup kept consistent for you.
  • Images and Links in the Visual Editor
    Insert, paste, drop and resize images, and link to elements, keys, topics or web addresses from a picker — without typing paths or IDs.
  • Reused Content, Keys and Link Titles
    The visual editor shows reused content, keys' texts, link targets' titles and keyed images resolved on the page, as your output will show them — and lets you open the source of reused content or make a local copy of it.
  • Problems and Quick Fixes in the Visual Editor
    The language server's errors and warnings are marked on the page where they are, and their quick fixes are one keystroke away.
  • Maps and Bookmaps in the Visual Editor
    A map or a bookmap opens in the visual editor as its title and one row per reference, each row showing the title of what it points to. Add references from a picker, change their targets and labels, and rearrange them by dragging or with Tab.
  • Properties View
    The Properties view lists the attributes of the element at the cursor — in the visual editor or the text editor — straight from your document type, and edits them one at a time.
