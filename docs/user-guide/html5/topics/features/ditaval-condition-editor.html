Visual DITAVAL Condition Editor

Build and preview DITAVAL conditional-processing profiles with a form-based editor instead of hand-writing XML.

Overview

While DITAVAL Support covers IntelliSense for authoring .ditaval files directly, the Visual DITAVAL Condition Editor is a dedicated panel for building and reviewing conditions without writing XML by hand. Run DITA: Edit DITAVAL Conditions on a .ditaval file — from the DITA Explorer, the file Explorer's context menu, or the active editor — to open it.

Editing Conditions

The panel groups the conditions by attribute (audience, platform, product, and so on): each value — from the file's <prop> rules and from your subject scheme — is a chip showing its action. Clicking a chip, or pressing Enter or Space on it, moves it to the next action: no rule, exclude, include, flag, and back to no rule (the rule is removed). To add a value, pick the attribute, type the value and press Enter (or Add Condition): it is added as an exclude rule. Each change is written to the .ditaval file, which you then save.

Everything works from the keyboard: Tab moves between the chips and the add form, the focus stays on the chip you changed (or in the value box after adding one), and screen readers announce each chip's value, its action and what pressing it does, then the change made.

Seeing the Effect

To see what a profile does to your content, choose the file as the preview filter (DITA: Set Preview DITAVAL Filter) and open the visual preview (DITA: Preview): excluded content disappears and flagged content shows its flags. Save the .ditaval file after changing a condition and the preview follows.

Condition Highlighting in the Editor

The text editor also shows what the preview's filter excludes and flags in the topic you are editing: see Condition Highlighting in the Editor.
