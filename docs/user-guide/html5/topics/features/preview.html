Live Preview

See your topic as a formatted page beside its source, updated as you type — without DITA-OT, without Java and without saving. The DITA-OT HTML5 preview is one command away.

Overview

DITA Craft has two previews:

Visual preview (default)
DITA: Preview (Ctrl+Shift+H) renders the topic itself, live, as a formatted page. It is built from grammars compiled from the DITA DTDs, so specializations render like the element they specialize.
DITA-OT preview
DITA: Preview with DITA-OT shows real DITA-OT HTML5 output, refreshed on save. Maps always preview with DITA-OT. To make it the default, set ditacraft.previewEngine to dita-ot.
  • Visual Preview
    A live page of the topic beside its source, rendered by DITA Craft itself as you type, with keys, reuse and link titles resolved.
