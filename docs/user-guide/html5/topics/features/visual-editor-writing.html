Writing on the Page

Type, make lists and steps, apply styles, and insert any element your document type allows — from the keyboard, the toolbar or the right-click menu.

Typing and Keys

You press DITA Craft writes
Enter in a paragraph or list item A new paragraph or item (without the original's @id)
Enter in a step's command A new <step><cmd>
Enter in an empty last list item Leaves the list: a paragraph after it
Enter at the end of a title Starts the short description (or the next paragraph)
Backspace at the start of a block Joins it to the previous one
Ctrl+B, Ctrl+I, Ctrl+U, Ctrl+E <b>, <i>, <u>, <codeph> (on and off)
Tab / Shift+Tab in a list item Nests the item in the previous one / moves it out (in a table: next / previous cell)
Ctrl+Z / Ctrl+Y Undo / redo on the page (and in the document)

Styles and the Insert Menu

The Style list turns the current paragraph into what the DTD allows there — a note, a code block, a lines block… Insert adds any block element the DTD allows after the current block: the common ones first, then all of them grouped by domain.

The Right-Click Menu

Right-click on the page, or press the Menu key or Shift+F10. The cursor moves where you clicked, unless you clicked inside the selection, which the menu then acts on.

Quick Fix…
On a problem: its fixes (see Problems and Quick Fixes in the Visual Editor).
Cut, Copy, Paste
Elements copied in the editor keep their structure and attributes; HTML pasted from other applications becomes paragraphs, lists, code blocks and bold/italic/code.
Insert after
Every block element the DTD allows after the current block.
Insert inline / Wrap in
Every phrase element the DTD allows at the cursor (xref, ph, uicontrol, filepath, term…): around the selected text or, with nothing selected, with its name as placeholder text to type over.
Image, Link…, Change to, Table
As in the toolbar (see Images and Links in the Visual Editor and Tables in the Visual Editor).
Select, Move up, Move down, Remove tags (keep content), Delete
On the element at the cursor, whose name is shown above them.
Attributes…, Show in source
The Properties View for that element; the text editor at that place.

The menus follow the document type exactly — a <title> offers phrases but no <xref>, a <note> takes paragraphs and lists but no <section> — and an item that would break the structure is greyed out. In every menu, the arrow keys move, → opens a submenu, ← or Escape closes it, Enter runs the item, and typing the start of a name jumps to it.
