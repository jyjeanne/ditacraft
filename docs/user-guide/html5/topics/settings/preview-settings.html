Preview and Visual Editor Settings

Configure the visual preview, the DITA-OT preview and the visual editor.

ditacraft.previewEngine

Type: String (visual or dita-ot)

Default: visual

Engine used by DITA: Preview: the live visual preview, or the DITA-OT HTML5 preview. Maps always preview with DITA-OT, and DITA: Preview with DITA-OT is available with either setting.

ditacraft.previewScrollSync

Type: Boolean

Default: true

Synchronizes the source editor with the preview (scrolling both ways, and the cursor when you click the page), and the source editor with the visual editor beside it (cursor and scrolling, character by character).

ditacraft.previewTheme

Type: String (auto, light or dark)

Default: auto

Colors of the preview and of the visual editor's page. auto follows VS Code's color theme.

ditacraft.previewCustomCss

Type: String (path)

Default: empty

A stylesheet applied to the previews and the visual editor, after the built-in one. ${workspaceFolder} is supported. The pages use the DITA-OT HTML5 class names, so a stylesheet written for your DITA-OT output works here too.

ditacraft.previewPageWidth

Type: Number (pixels)

Default: 760

Width of the page in the visual preview and the visual editor; 0 makes it fluid.

ditacraft.previewShowMarkup

Type: Boolean

Default: false

Initially show what a published page does not show: prolog metadata, comments, processing instructions, index terms, data and draft comments. Show markup in the toolbar toggles it.

ditacraft.previewShowExcluded

Type: Boolean

Default: false

Dim the content the active DITAVAL filter excludes instead of removing it.

ditacraft.previewResolveReferences and ditacraft.previewResolveOnSave

Type: Boolean

Default: true

Resolve keys, reused content, cross-reference titles and coderef/mathmlref/svgref targets in the visual preview; and resolve them again (re-reading reused files and keys) when the previewed file is saved.

ditacraft.previewUpdateDelayMs

Type: Number (milliseconds)

Default: 150

Delay between an edit and the visual preview's update.

ditacraft.previewAutoRefresh

Type: Boolean

Default: true

Refresh the DITA-OT preview when the file is saved. (The visual preview is always live.)

ditacraft.imagePasteFolder

Type: String (path)

Default: images

Where the visual editor saves images pasted into a topic (or dropped from outside VS Code): a folder relative to the topic's folder, or absolute; ${workspaceFolder} is supported. Files are named after the topic: <topic>-1.png, <topic>-2.png…

Example

{
    "ditacraft.previewTheme": "light",
    "ditacraft.previewPageWidth": 820,
    "ditacraft.previewCustomCss": "${workspaceFolder}/css/preview.css",
    "ditacraft.imagePasteFolder": "${workspaceFolder}/images/screenshots"
}
